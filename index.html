Массивы и цикл for в JavaScript

Нажимай, считай и смотри, как программа шаг за шагом проходит по массиву.

1Массив: ряд пронумерованных коробок

Массив — это одна переменная, в которой хранится много значений по порядку. Представь ряд шкафчиков в раздевалке: у каждого свой номер, а внутри что-то лежит.

👆 Нажми на любую коробку
Главное правило: нумерация (индекс) начинается с 0, а не с 1! Поэтому в массиве из 4 элементов у последнего индекс 3, то есть length − 1.

2Цикл for: повтори действие много раз

Без цикла, чтобы показать все фрукты, пришлось бы писать console.log(fruits[0]), console.log(fruits[1]), console.log(fruits[2])… А если элементов 1000? Цикл делает это за нас: переменная i по очереди становится 0, 1, 2, 3… и «ходит» по коробкам.

for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}

① Старт

let i = 0

Создаём счётчик. Выполняется только один раз в самом начале.

② Условие

i < fruits.length

Проверяется перед каждым кругом. true — идём дальше, false — цикл закончен.

③ Тело

{ … }

То, что повторяется. Здесь fruits[i] — это «коробка номер i».

④ Шаг

i++

После каждого круга увеличиваем i на 1 и возвращаемся к условию.

Порядок всегда такой: старт → условие → тело → шаг → условие → тело → шаг → … → условие false → выход.
